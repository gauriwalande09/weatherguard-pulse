# WeatherGuard AI Pro

Build the complete polished frontend prototype for WeatherGuard AI exactly as specified: an AI-powered Automatic Weather Station anomaly detection and sensor health monitoring platform for SIH26073. Implement all responsive pages, navigation, modular components/services/mock data, live simulation, demo mode scenarios, anomaly table/details/explainability, fault vs genuine weather comparison, sensor health/predictive maintenance, analytics and stations. Use the defined Poppins dark navy/blue/teal visual system and ensure all key interactions work with no backend required, while keeping a backend-ready API service layer.
